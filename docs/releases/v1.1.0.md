# agents-feedback v1.1.0

## Repository-Local Learning Loop

Version 1.1.0 makes the feedback loop easier to discover, install, and use. It connects relevant feedback discovery with capture before work and adds a safe boundary for per-clone machine context.

## What This Provides

The release artifact installs a dependency-free `.agents/feedback` scaffold with shared lifecycle records, ignored local additions, one concise record schema, one flat plan schema, and a state helper for humans and agents.

## Highlights

- Inspects relevant active feedback before substantial or unfamiliar work.
- Adds `--active`, `--brief`, `--area`, `--path`, and `--shared-only` state options.
- Uses lifecycle folders as the only record status.
- Separates factual observations from hypotheses and confidence.
- Updates matching observations before creating duplicates.
- Adds generalized environment context and ignored local instructions and records.
- Makes safety review and triage authority explicit.
- Uses flat inline plans while keeping larger work in normal project planning.
- Supports fresh installation without Node.js.
- Requires staged upgrades for existing installations.
- Validates complete YAML fixtures with repository-only tooling.
- Builds reproducible ZIP artifacts and SHA-256 checksums.
- Reorganizes public documentation around product value, three-step installation, first use, collaboration, upgrades, and troubleshooting.

## Installation

Download `agents-feedback-v1.1.0.zip` to install this release. The similarly named `agents-feedback-v1.1.0.zip.sha256` file is optional verification metadata; do not extract it.

For a fresh installation, first confirm `.agents/feedback` does not exist. An existing `.agents` directory is fine because the ZIP adds only its `feedback` subtree. Extract at the target repository root, cancel if the tool requests an overwrite, and ask an agent to read `.agents/feedback/AGENTS.md`.

For an existing installation, extract into a temporary staging directory and ask an agent to read the staged `.agents/feedback/UPGRADE.md`. Never extract directly over existing records or local content.

The [v1.1.0 getting-started guide](https://github.com/TechSpokes/agents-feedback/blob/v1.1.0/docs/getting-started.md) covers verification, first use, collaboration, upgrades, and troubleshooting.

## Validation


The release candidate includes `dist/agents-feedback-v1.1.0.zip`, its SHA-256 checksum, and a manifest whose entries match the ZIP.

## Notes

The package release is v1.1.0. The only record and plan contracts remain `feedback-record.v1` and `feedback-plan.v1`; there is no legacy dispatcher or migration layer.

Tagging, pushing, drafting on GitHub, and publication remain maintainer-approved actions.
