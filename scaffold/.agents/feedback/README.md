# feedback

This folder is for repository-local agent observations that improve future work in this repository. It is not memory, not a task tracker, not canonical docs, and not secrets or log storage.

## Contents

- `AGENTS.md` contains folder-scoped agent instructions.
- `AGENTS.final.md` contains operational instructions copied over `AGENTS.md` after installation wiring is complete.
- `records/` contains lifecycle folders for YAML feedback records.
- `schemas/` contains JSON schemas for IDE validation.
- `templates/` contains YAML templates and installation snippets.
- `tools/` contains portable helper scripts when installed.

## Purpose

Use this folder when an agent notices repository-specific friction, missing instructions, setup problems, tooling problems, verification gaps, or completed improvements that would make future work faster or less error-prone.

## Boundaries

Do not store secrets, credentials, raw private logs, screenshots, generated artifacts, customer data, private tokens, or general task notes here.

Promote durable rules to the repository's canonical `AGENTS.md`, `README.md`, docs, scripts, or tests.
