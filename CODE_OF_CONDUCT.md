# Code of Conduct

## Our Standard

This project expects respectful, constructive participation. Contributors should focus on the work, assume good faith where reasonable, and avoid harassment, personal attacks, or disruptive behavior.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private information without explicit permission.
- Repeatedly derailing technical discussion after maintainers ask for focus.
- Sharing secrets, credentials, private logs, customer data, private issue text, screenshots, large logs, or private tokens in public project spaces.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, discussions, or pull requests that violate this code of conduct. Maintainers may also restrict participation for repeated or severe violations.

## Reporting

Report conduct concerns to the repository maintainer privately. Do not open a public issue for sensitive personal or security-related reports.
