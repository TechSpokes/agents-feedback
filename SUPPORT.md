# Support

Use the channel that matches the request.

## Questions

Start with the [getting-started guide](docs/getting-started.md), which is the source of truth for installation, first use, upgrades, and troubleshooting. Use [GitHub Discussions](https://github.com/TechSpokes/agents-feedback/discussions) for questions, ideas, and general design discussion.

## Bugs and Feature Requests

Use [GitHub Issues](https://github.com/TechSpokes/agents-feedback/issues) for reproducible bugs and concrete feature requests. Include the version, operating system, relevant commands, expected behavior, actual behavior, and sanitized evidence.

## Security

Use the [security policy](SECURITY.md) for vulnerabilities or sensitive reports. Do not post secrets, credentials, private logs, customer data, private issue text, screenshots, large logs, or private tokens in public channels.
